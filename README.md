# Отчет по перестрахованию: КСЖ Республики Казахстан

Ежеквартальный анализ финансового состояния компаний по страхованию жизни (КСЖ) РК — партнеров по перестрахованию — для коллегиального органа. Период: 01.01.2026 → 01.10.2026, нормативы — по 01.11.2026.

## Состав

| Путь | Что это |
|---|---|
| [claude/metodika-otcheta-ksj.md](claude/metodika-otcheta-ksj.md) | Методика расчетов и источники |
| `data/*.csv` | Исходные данные (единственный источник для портала) |
| `scripts/build-data.ps1` | Собирает `portal/data.js` из CSV |
| `scripts/serve.ps1` | Локальный сервер для просмотра портала |
| `portal/` | Веб-портал мониторинга КСЖ (статический, без зависимостей) |

Внутреннее описание проекта (PRO.md) в репозиторий не входит.

## Запуск портала

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-data.ps1
powershell -ExecutionPolicy Bypass -File scripts\serve.ps1
```

Затем откройте http://localhost:8080. Портал состоит из статических файлов, поэтому папку `portal/` можно разместить на GitHub Pages или любом веб-сервере.

## Обновление в следующем квартале

1. Скачайте новые файлы НБРК (см. методику).
2. Обновите `data/*.csv`: числа с точкой, млрд ₸; пустая ячейка означает «н/д».
3. Запустите `scripts\build-data.ps1` и проверьте портал.
4. Обновите внутренний отчет и презентацию.
